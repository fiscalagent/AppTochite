> Версия 1.64.x · Обновлено 2026-05-26

---

## Нижняя навигация (Bottom Nav)

Постоянно видна на всех экранах.

```
┌─────────────────────────────────────────┐
│  [Клиенты]   [ + FAB ]   [История]  [Справочник]  │
│      /           /sh/new    /history   /ref/stones  │
└─────────────────────────────────────────┘
```

| Элемент | Куда | Экран |
|---|---|---|
| Клиенты (иконка) | `/` | C-1 Список клиентов |
| **+ (FAB)** | `/sharpenings/new` | Z-1 Новая заточка |
| История (иконка) | `/history` | H-1 Лента заточек |
| Справочник (иконка) | `/reference/stones` | S-1 Справочники |

> **Вкладки переключаются через `replace`** (Клиенты / История / Справочник) — переход между корневыми разделами не добавляет запись в историю. Поэтому системная кнопка «назад» с любой вкладки сразу выходит из приложения, а не отматывает предыдущие вкладки.
> FAB **+** — наоборот, `push`: открытие новой заточки добавляет шаг, чтобы «назад» отменяло форму и возвращало туда, откуда открыли.

## Z-1 — Форма заточки (`/sharpenings/new`, `/sharpenings/:id/edit`)

Форма — **2-шаговый stepper**.

```
┌──────────────────────────────────────┐
│  ◀  НОВАЯ ЗАТОЧКА  [🎙 диктовка]    │
│  ● Шаг 1: Приёмка  ○ Шаг 2: Заточка │
│  ─────────────────────────────────── │
│  ШАГ 1                               │
│  Клиент:   [Autocomplete ▼]          │
│  Нож:      [Autocomplete ▼]          │
│  Сталь:    [Autocomplete ▼]   HRC:[] │
│  Состояние: [заточка] [правка] [рем] │
│  Принят:   [дата]                    │
│  ─────────────────────────────────── │
│             [ПРИНЯТЬ НОЖ]            │
└──────────────────────────────────────┘
         ↓ После «ПРИНЯТЬ НОЖ»
┌──────────────────────────────────────┐
│  PhotoSourceSheet: Фото «До»?        │
│  [Камера]  [Галерея]  [Пропустить]   │
└──────────────────────────────────────┘
         ↓ После выбора/пропуска
┌──────────────────────────────────────┐
│  ◀  ЗАТОЧКА  [🎙 диктовка]          │
│  ✓ Шаг 1   ● Шаг 2: Заточка        │
│  ─────────────────────────────────── │
│  Угол:     [___]°                    │
│  Камни:    [Autocomplete ▼] + добавить│
│  Требуется:[заточка] [правка РК]...  │
│  Цена:     [___] ₽                   │
│  Комментарий: [___]                  │
│  Фото «До»  +[📷]                   │
│  Фото «После» +[📷]                 │
│  ─────────────────────────────────── │
│  [Сохранить]    [ЗАТОЧЕНО]           │
└──────────────────────────────────────┘
```

| Действие | Куда |
|---|---|
| `◀` (назад) | Предыдущий экран (`navigate(-1)`) |
| `ПРИНЯТЬ НОЖ` (шаг 1) | PhotoSourceSheet → Шаг 2 (внутри экрана) |
| Фото «До»: Камера / Галерея / Пропустить | Шаг 2 (остаётся на Z-1) |
| `Сохранить` (шаг 2, статус = принят) | Z-2 `/sharpenings/:id` (`replace` — форма не остаётся в истории) |
| `ЗАТОЧЕНО` (шаг 2, статус → done) | PhotoSourceSheet «После» → Z-2 `/sharpenings/:id` |
| Новый камень (мини-форма) | Открывается модал внутри Z-1 |

> Если открыт из C-2 с `?clientId=X` — поле клиента скрыто и предзаполнено.  
> Если открыт из Z-2 «Повторить» — все поля предзаполнены данными предыдущей заточки.  
> Если открыт из Z-2 «ЗАТОЧИТЬ» — сразу переходит на Шаг 2 (`?step=2`).

## Поведение кнопки «Назад»

Два «назад» работают через единый стек истории и в большинстве экранов делают одно и то же — снимают один шаг:

- **Системная стрелка телефона** — идёт строго по стеку истории браузера.
- **Внутренняя ◀** (слева вверху) — `navigate(-1)`, тот же эффект. Есть только на вложенных экранах (C-2, C-3, Z-1, Z-2, BK-1, A-1); на корневых вкладках (C-1, H-1, S-1/2/3) её нет — там только нижняя навигация.

**Правила стека:**

| Тип перехода | История | Примеры |
|---|---|---|
| Переключение корневых вкладок | `replace` (не копится) | Клиенты ↔ История ↔ Справочник |
| Открытие вложенного экрана | `push` (+1 шаг) | карточка клиента, запись заточки, формы, FAB |
| Сохранение формы | не оставляет форму в истории | новый клиент/заточка → `replace`; правка → `navigate(-1)` |

Итог: хождение по вкладкам не накапливает историю → выход из приложения за **1-2 нажатия** системной «назад».

**Единственное расхождение** — форма заточки Z-1 (2 шага): внутренняя ◀ на шаге 2 возвращает на шаг 1 (остаётся в форме), а системная «назад» закрывает форму целиком (шаги — внутреннее состояние, в историю не пишутся). Это сделано намеренно.

## Модальные компоненты (не меняют URL)

| Компонент | Где появляется | Действие |
|---|---|---|
| **ConfirmModal** | C-2 (удалить клиента), Z-2 (удалить заточку) | OK → удаление + навигация; Отмена → закрыть |
| **PhotoSourceSheet** | Z-1 (после шага 1, фото «До»/«После»), C-2 (аватар «Я») | Камера / Галерея / Пропустить → возврат в экран |
| **PhotoLightbox** | Z-1, Z-2, C-2 | Просмотр фото на весь экран; закрыть → экран |
| **PhotoReportSheet / PhotoShareSheet** | Z-2 (кнопка «Поделиться фото») | Генерация/шаринг; закрыть → экран |
| **OnboardingSheet** | C-1 (первый запуск) | Закрыть → C-1 |
| **BackupReminder (модалка)** | Любой экран, info ≥7д / warn ≥14д или ≥10 новых записей | Сделать бэкап / Напомнить завтра |
| **BackupCriticalBanner** | Любой экран кроме /backup, при critical (≥30д без бэкапа и ≥5 заточек) | Тап → BK-1; не скрывается до бэкапа |
| **BrowserWarning** | App (Telegram WebView) | Закрыть → экран |
| **StorageWarning** | App (заполнение >90%) | Закрыть → экран |
| **Форма камня/стали/ножа** (inline portal) | S-1/2/3, Z-1 | Сохранить / Отмена → экран |

## Условные переходы

| Условие | Поведение |
|---|---|
| `isSelf: true` (клиент «Я») | Нет кнопок «Изменить» и «Удалить» в C-2 |
| `status === 'accepted'` | Кнопка `ЗАТОЧИТЬ` видна в Z-2 |
| `status === 'done'` | Кнопка `ЗАТОЧИТЬ` скрыта; `doneAt` заполнен |
| Голосовой ввод включён | Mic-кнопки видны в Z-1; кнопка диктовки в шапке |
| Фото есть | `Поделиться фото` видно в Z-2 |
| `hasUpdate: true` | Точка-индикатор на иконке 💾 в C-1 |
| `clientId` в query string Z-1 | Поле «Клиент» скрыто и предзаполнено |
| `?step=2` в Z-1 | Открывается сразу на шаге 2 |
| Repeat state в Z-1 | Все поля предзаполнены из предыдущей заточки |
