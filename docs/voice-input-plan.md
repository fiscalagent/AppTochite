# Голосовой ввод — план реализации

## Концепция

Голос как дополнение к текстовому вводу (progressive enhancement). Форма работает без голоса в штатном режиме, микрофон только ускоряет заполнение. В оффлайне фича недоступна, но ничего не ломается.

---

## Пилот — форма заточки (Z-1, SharpeningForm)

### Покрытые поля

| Шаг | Поле | Тип ввода | Примечание |
|-----|------|-----------|------------|
| Приёмка | Клиент | Autocomplete | Fuzzy match по справочнику |
| Приёмка | Нож | Autocomplete | Fuzzy match по справочнику |
| Приёмка | Примечания | Textarea | Свободный текст |
| Заточка | Камни | Autocomplete | Только существующие, без создания нового |
| Заточка | Угол | Number input | Распознаём число |
| Заточка | Примечания | Textarea | Свободный текст |
| Заточка | Цена | Number input | Распознаём число |
| Заточка | Статус | Toggle | Только `accepted → done`, если распознали ключевое слово |

### Логика статуса

Дефолт — `accepted`. Если в распознанном тексте есть ключевое слово из списка — переключаем в `done`:

```
готово, готов, выполнено, сделано, закончил, завершено
```

Переход однонаправленный (только `accepted → done`). При срабатывании — тост «Статус изменён на "Готово"».

### Навигация

Голос управляет **только содержимым** текущего поля. Навигация между полями и шагами — только руками. Фокус не перескакивает автоматически.

### Оффлайн-поведение

- Кнопка микрофона остаётся видимой, но `disabled` + прозрачная
- Тап по недоступной кнопке → тост «Голосовой ввод недоступен офлайн»
- Проверка: `navigator.onLine` + события `online/offline` (реагирует динамически)

## Технические компоненты

### `useVoiceInput` — хук

```
src/hooks/useVoiceInput.ts
```

Инкапсулирует Web Speech API. Возвращает:

```typescript
{
  isAvailable: boolean,   // браузер + онлайн
  isListening: boolean,
  start: (onResult: (text: string) => void) => void,
  stop: () => void,
}
```

### `MicButton` — компонент

```
src/components/MicButton/
```

Состояния кнопки:
- **Доступна** — иконка микрофона, активная
- **Слушает** — анимация (пульсация), акцентный цвет
- **Недоступна** — иконка микрофона, `disabled`, прозрачная

### Feature flag

```
src/config/features.ts
```

```typescript
export const FEATURES = {
  voiceInput: true,  // false — полный откат, кнопки не рендерятся
};
```
