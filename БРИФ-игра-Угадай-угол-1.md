# Игра «Угадай угол» — бриф для Claude Code

## Контекст
Вторая мини-игра для **AppTochite** (PWA-журнал заточника, GitHub Pages,
репозиторий `fiscalagent/AppTochite`). Первая игра — «Собери прогрессию»
(тренажёр зернистостей). Эта — тренажёр глазомера на угол заточки.

Готовый прототип лежит рядом: `angle-game.html` — самодостаточный, чистый
JavaScript + SVG, без зависимостей, без сборки, без бэкенда. Работает офлайн.

---

## Суть игры
На экране сбоку нарисован клин режущей кромки под случайным углом.
Игрок слайдером оценивает угол заточки **НА СТОРОНУ** (10–35°) и жмёт «Ответить».
Игра показывает истинный угол, накладывает ответ игрока и выдаёт вердикт.

**Ключевое понятие:** угол на сторону, НЕ полный.
20° на сторону = 40° полный (TBA). Под цифрой всегда дублируется полный (×2).
Дуга и метка «?» на картинке показывают именно угол НА СТОРОНУ —
от оси-биссектрисы до одной грани, а не раствор между гранями.

## Точность
- промах ≤1° → «в точку» (v-perfect)
- промах ≤3° → «засчитано» (v-ok), серия растёт
- промах >3° → мимо, серия обнуляется

## Прогрессия (звания по рекорду серии)
- 0+  «Глаз новичка»     — без наклона
- 3+  «Намётанный глаз»  — наклон ~15°
- 6+  «Глазомер мастера» — наклон ~28°
- 10+ «Живой угломер»

## Хард-режим «Наклон»
Включается по званию (по текущей серии). Вся фигура клина поворачивается
вокруг кончика на N° от горизонта (вверх/вниз, знак случайный).
- Угол ЗАТОЧКИ при этом НЕ меняется — двигается только наклон всей фигуры.
- На картинке есть пунктирный горизонт-ориентир, относительно него наклон виден.
- Цель усложнения: глаз сбивается, хочет мерить от горизонта, а надо между гранями.
- ВАЖНО: проверка всегда по ИСТИННОМУ углу заточки, наклон только мешает оценить,
  но НЕ влияет на засчёт. Иначе игра наказывает за собственное искажение.
- Бейдж «◣ наклон» загорается при наклонном раунде (без числа — чтобы не подсказывать).

## Контекстная подсказка (после ответа)
По истинному углу показывается типовое применение:
10–14 бритва · 15–17 яп. кухонник · 18–20 евр. кухонник ·
21–25 EDC/складной · 26–30 турист/рубящий · 31–35 топор/мачете.

  единый профиль, а не отдельный счётчик в localStorage/памяти.
- Сохранять рекорд между сессиями (IndexedDB, как остальные данные приложения).

- Доп.усложнение «угол вдоль клинка»: показывать угол в разных точках
  от пятки до острия (на изгибе брюшка угол apex'а меняется) — отдельный режим.
- Разные типы подвода: прямой / линзовидный / с микроподводом.
- Сверить диапазоны углов и контекст применения с матчастью приложения,
  чтобы цифры в игре совпадали со справочником.

## Технические заметки
- Клин строится математикой из угла (SVG), картинки не нужны.
- Наклон: ось-биссектриса = −tilt по экрану (Y растёт вниз);
  грани = ось ± угол_на_сторону. Истинный угол от tilt не зависит.
- Файл проверен, JS-синтаксис чистый. Drag/тач не используются — только слайдер.
